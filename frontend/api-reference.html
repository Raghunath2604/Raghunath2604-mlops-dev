MLOps.dev REST API

API Reference v1

Base URL: https://api.mlops.dev/v1
All requests require Authorization: Bearer <api_key>.
All responses are JSON. All timestamps are ISO 8601 UTC.

The Python SDK wraps this API: pip install mlops-dev. See PyPI → or GitHub →

Authentication

All API requests require an API key. Get yours from Dashboard → Settings → API Keys.

HTTP HEADER
Authorization: Bearer mlops_live_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
CURL EXAMPLE
curl https://api.mlops.dev/v1/devices \ -H "Authorization: Bearer $MLOPS_API_KEY"
PYTHON SDK
import mlops # From env variable MLOPS_API_KEY client = mlops.Client() # Or explicit client = mlops.Client(api_key="mlops_live_xxx")

Errors

Standard HTTP status codes. Error responses include a JSON body with error and optional code fields.

StatusMeaning
200Success
400Bad request — invalid parameters
401Unauthorized — invalid or missing API key
404Not found — device, model, or deployment does not exist
429Rate limited — check Retry-After header
500Internal server error — contact hello@mlops.dev

List devices

GET /devices List all registered devices
ParameterTypeDescription
statusstringFilter: online | offline | drift | error
hw_classstringFilter by hardware class e.g. jetson_orin
limitintegerPage size (default 100, max 500)
offsetintegerPagination offset
RESPONSE
{ "data": [ { "id": "jetson-prod-01", "name": "Factory Floor A — Camera 1", "status": "online", "hw_class": "jetson_orin", "arch": "arm64", "model_name": "defect-detector", "model_tag": "v2.0", "model_format": "tensorrt", "drift_score": 0.12, "latency_ms": 3.8, "last_seen": "2025-07-15T10:42:00Z", "agent_version": "0.6.0", "ram_mb": 14 } ], "total": 842, "limit": 100, "offset": 0 }

Create deployment

POST /deployments Deploy a model to device(s)
FieldTypeDescription
model_name*stringModel name e.g. defect-detector
model_tag*stringVersion tag e.g. v2.0
target*stringDevice ID, hw_class, or "all"
stagesarrayStaged rollout config (optional)
health_gateobjectaccuracy_delta, latency_delta thresholds
stage_intervalstringTime between stages e.g. "30m"
REQUEST BODY — canary rollout
{ "model_name": "defect-detector", "model_tag": "v2.0", "target": "all", "stages": [ { "hw_class": "jetson_orin", "count": 1 }, { "hw_class": "jetson_orin", "pct": 100 }, { "hw_class": "jetson_nano", "pct": 25 }, { "hw_class": "all", "pct": 100 } ], "health_gate": { "accuracy_delta": -0.03, "latency_delta": 0.20 }, "stage_interval": "30m" }

Audit log

GET /audit Immutable deployment audit log

Returns paginated, immutable audit records. Required for FDA 21 CFR Part 11 and ISO 13485 compliance.

ParameterTypeDescription
device_idstringFilter by device
fromstringISO 8601 start date
tostringISO 8601 end date
event_typestringdeployment | drift | rollback | auth
formatstringjson | csv (default: json)
limitintegerMax records (default 100)
CURL — export CSV for FDA audit
curl "https://api.mlops.dev/v1/audit?device_id=jetson-prod-01&from=2025-01-01&to=2025-07-15&format=csv" \ -H "Authorization: Bearer $MLOPS_API_KEY" \ -o audit-q1q2-2025.csv
